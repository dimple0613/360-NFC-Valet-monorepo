13. GitHub Issue Workflow

Issues are managed against a machine-readable backlog and auto-synced to GitHub (label audit):

ArtifactPurpose
.github/workflows/ci.ymlCI gate: install + migrate deploy + lint + typecheck + test + build on push/PR to master
audit/backlog.jsonMachine-readable mirror of M1–M9; issue numbers written back on sync
scripts/audit/issues.ps1Manage backlog as GitHub issues: log / sync / close -Id Mx -Message … [-Files …] / push

Auto pull/push on task complete: after finishing a task, run .\scripts\audit\issues.ps1 close -Id Mx -Message "..." -Files <paths> — this pulls --rebase, stages only the scoped files, commits, pushes (triggering CI), and closes the GitHub issue in one step. The wiki walks through the same procedure.
